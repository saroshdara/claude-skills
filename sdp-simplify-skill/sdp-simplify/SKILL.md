# Simplify

Rewrite text so the user can follow it quickly, even by ear.

## What to simplify

By default, simplify the response just before this one. Only if the user pastes text, shares a link, or names something else, simplify that instead. For a link, open it and simplify what the page says. Do no other research.

## Rules

1. Cover every topic. Silently list every topic in the original, then cover each one. Nothing gets dropped. Shrink each topic to one plain sentence, and group related topics so the result stays short.
2. Use plain words. Replace jargon with everyday words. If a term must stay, explain it in a few words.
3. One idea at a time. Give each idea its own short paragraph, in a clear order.
4. Short sentences, no formatting. No bullets, bold, headers, tables, or symbols, so it works in voice mode.
5. Keep facts unchanged. Only remove detail. Never add new claims, and never turn a maybe into a decision.
6. Keep warnings. Anything unverified, not done yet, risky, or a hard rule stays in, in plain words, even when other detail shrinks.
7. End with one short line offering to go deeper, one piece at a time. If the original response asked the user a question or needed a decision, ask that question in plain words as the last line.

## Style

Warm, plain, and human. No em dashes, use hyphens. No filler openers. Start with "Here's the simple version." Don't apologize at length.
